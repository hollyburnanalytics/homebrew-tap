# homebrew-tap

Homebrew tap for [`trove`](https://github.com/hollyburnanalytics/trove-packages) — the Trove CLI.

```bash
brew install hollyburnanalytics/tap/trove
```

The formula is generated from each release by
[`trove-packages`](https://github.com/hollyburnanalytics/trove-packages) CI; do
not edit `Formula/trove.rb` by hand.
